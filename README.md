- 🚀 Software engineer at **Snabbit**, building production mobile apps with **Flutter**
- 🔄 I like hard real-time problems: **offline-first sync, CRDTs, WebSockets**
- 🏗️ I write apps with **Clean Architecture**, feature-first modules and event-driven state

- 📚 Currently sharpening **system design** and **machine coding**
